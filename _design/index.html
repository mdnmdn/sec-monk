◆ sec-monk — interface design

Design system, sample pages and component storybook of the local web interface (secmonk ui). Requirements, views and navigation: _docs/features/web-ui.md; architecture: _docs/tech/web-ui.md.
One component library
Every page here loads src/secmonk/web/static/css/secmonk.css, js/secmonk-ui.js and js/secmonk-views.js — the files the app serves. Sample pages are the real app on mock data generated from the test fixtures (scripts/design_mock.py → mock/data.js). Open them directly (file://) or with python3 -m http.server from the repository root. Vue is vendored (src/secmonk/web/static/vendor): no network needed.

Principles

  • Explain, don't just list: every badge and flag carries its meaning (tooltip, detail text).
  • Risk first: findings and flags are the only saturated colors; everything else stays neutral.
  • List → detail drawer: never lose the list's filters and scroll; every state has a URL.
  • Same anatomy everywhere: header → context → toolbar → content → drawer.
  • Data is text: rendered with interpolation only, never as HTML.
